# Pixel & Co. — Creative Studio Landing Page

A responsive landing-page concept for a fictional independent digital studio. The design uses a warm editorial palette, bold typography, geometric CSS artwork, and clear calls to action.

## Features

- Responsive layout for desktop and mobile
- Mobile navigation with accessible expanded-state handling
- Services, approach, about, and contact sections
- Custom geometric hero artwork built with CSS (no image assets required)
- Semantic HTML, descriptive metadata, and reduced-motion support
- Dynamic copyright year

## Run locally

No build tools or package installation are required.

1. Clone or download this repository.
2. Open `index.html` in a browser.

For a local development server, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize before real-world use

- Replace the fictional studio copy and service details with accurate business information.
- Replace `hello@pixelandco.example` with a real contact address.
- Connect the contact action to a real enquiry form or CRM if required.
- Review font loading and privacy requirements for your deployment environment.
